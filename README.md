# frameandfame.in

Website for Frame &amp; Fame — a video-led marketing agency in Kokrajhar, Assam.

Plain HTML, no build step. Open `index.html` to edit.

## Files

| File | What it is |
|---|---|
| `index.html` | The whole site — markup, styles and scripts in one file |
| `assets/logo.png` | F&F mark, white, transparent background |
| `assets/founder.jpg` | Founder portrait used in the About section |
| `assets/og.jpg` | Preview card shown when the link is shared |
| `assets/icon-*.png`, `favicon.ico` | Browser and phone icons |
| `CNAME` | Tells GitHub Pages the site lives at frameandfame.in |
| `robots.txt`, `sitemap.xml` | For search engines |
| `.nojekyll` | Stops GitHub trying to process the files |

## Editing

Text, prices and client names are in `index.html`. Search for the words you
want to change — everything is plain English in the markup.

To change the phone number, search for `70862 69537` and replace every match
(it appears in the contact link, the structured data and the copy).

## Publishing

Pushing to the `main` branch publishes the site. GitHub Pages redeploys within
about a minute.
